# OneTerm 标准示例数据集说明

本目录存放用于功能验收、Mock 模式与「一键载入示例数据」的标准教务数据。

## 文件说明

- `semester-sample.txt`：原始粘贴文本，包含：
  - **课表文本（3 条 `course`）**：《算法设计与分析》、《操作系统》、《计算机网络》实验课
  - **考试通知（3 条 `exam`）**：《算法设计与分析》期中随堂测验、《操作系统》期中上机考核、《计算机网络》期末考试
  - **作业截止通知（2 条 `deadline`）**：《算法设计与分析》实验报告截止、《计算机网络》抓包报告截止
  - **社团活动通知（1 条 `activity`）**：ACM 协会秋季招新沙龙暨算法分享会
- `expected-events.json`：期望抽取的 9 条结构化事件（每条均包含精确的 `sourceText` 原文片段）。
